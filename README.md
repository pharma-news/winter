# до нового года · зимняя ночь

Тихий зимний сайт-настроение по мотивам кадра из «Жил-был пёс» (Союзмультфильм, 1982).
Никаких слов, кроме цифр: вверху — отсчёт до нового **2027** года (по Москве), внизу — зима.

Что можно делать на странице:

- кликнуть по снегу — снег вздрагивает и рассыпается искрами;
- подвести курсор — снежинки обходят тёплое дыхание, даль немного ходит параллаксом;
- дёрнуть тяжёлую заснеженную ветку вверху справа — снег осыпается;
- кликнуть по тёмному небу — там загорается твоя звезда;
- кликнуть по жёлтым окнам — света становится чуть больше;
- нажать `s` — поднять метель, `f` — пустить салют, `a` — позвать северное сияние, `пробел` — россыпь искр;
- кнопкой справа вверху включить зимний гул: шум ветра, низкий гул глубины и редкие колокольчики (собирается на месте через Web Audio, файлов нет).

Сама зима тоже живая, без кликов: из труб идёт дым, по карнизу и на ветке мигает гирлянда,
за стёклами иногда мелькают тени жильцов и кошка на подоконнике, окна горят неровно,
небо изредка открывается в северное сияние, а ещё реже — длинные салюты с долгими углями.

## Из чего сделано

- `index.html` — сцена целиком нарисована в SVG: сугробы слоями (чем ближе — тем светлее),
  чёрная даль как бездна, изба-сруб с тёплыми окнами, щелью света у двери и снежным одеялом на крыше,
  деревня на горизонте, лес отдельным тёмным гребнем, кривые заборы без перекладин-крестов,
  тени горбылей на светлом снегу.
- `app.js` — снег в четыре слоя на canvas: дальняя пыль, снежинки, расфокус у «камеры», плывущая снежная мгла;
  лес и заборы строятся процедурно (один и тот же кадр при каждой загрузке);
  северное сияние и салюты — тоже canvas, с additive-слоем, углём и искрами;
  плюс отсчёт, параллакс, метель и звук.
- `styles.css` — палитра снята прямо с кадра мультика: `#01034a → #02045c → #000006` в небе
  (тот самый взгляд в зимнюю бездну) и `#0c1846 → #4f75c8 → #88aede` в снегу.
  Виньетка и плёночное зерно держат кадр.

Картинок, шрифтов, статистики и рекламы нет. Работает офлайн: достаточно открыть `index.html`.

## Локально

```bash
python3 -m http.server 8000
```
